# AssessAI-AI-Powered-SHL-Assessment-Recommender
Developed **RecruitIQ**, an AI-powered assessment recommendation system that helps recruiters identify suitable SHL assessments from a catalog of 34+ tests. Built a RAG pipeline using **FAISS**, **Sentence Transformers**, **FastAPI**, and **Llama-3.3-70B (Groq)** to deliver context-aware recommendations and explanations.
